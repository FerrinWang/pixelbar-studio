# 时钟冒号闪烁

时钟元素显示 HH:MM，不再提供秒数字。`blinkColon=false` 为静态冒号；`true` 为亮、灭各 0.5 秒的装饰性动画。网页按 500 ms 相位渲染，100 ms 检查一次；浏览器后台节流可能影响预览。

推送当前画布时，所有数据冻结为同一快照，生成冒号亮 / 灭两帧，上传到已验证的 7/15 路径，间隔字段 500。设备实际半秒间隔仍需实屏确认，不能承诺起播时刻与真实秒同步。此次功能不自动向设备上传。

手动上传两帧后关闭自动推送，以免立即覆盖动画。若需后台更新，请保存场景后明确重新开启自动推送：后台同样生成两帧，比较完整帧数据与间隔，仅在数据或分钟变化时重新上传，不因冒号相位变化重复传输。重新上传仍可能出现固件上传提示；分钟不是由设备本地时钟推进，关闭自动更新后数字停在上传时刻。

为兼容旧场景，旧 `seconds` 属性在没有 `blinkColon` 时作为闪烁标志读取，不再渲染秒数字；新增开关写入 `blinkColon`，其值优先。
