# 中文与传输限制

拖入「中文 / 通用文字」，输入中英文并选择 Fusion 10、Fusion 12 或 Ark 12。英文组件还可以选择原有 3×5 紧凑字体。支持换行、整数放大、裁切提示与适应文字尺寸。

浏览器使用随 App 打包的开源字库直接生成点阵；点阵存入场景 JSON，关闭浏览器后后台输出保持一致。旧点阵保留，主动切换字体后迁移。此组件用于编辑器输入的静态文字；动态中文需要插件提供字形/点阵。来源、许可与重建说明见 FONTS.md。

## 原版 PixelBar 的图片上传提示

当前自定义画布使用已验证的 0x17 文件上传协议。设备固件在上传时显示「图片上传中…」，网页端不能删除固件绘制的提示。帧去重只能减少上传次数，不能让实际上传静默。

已检查官方驱动：PixelCustomWork 的 cache 参数是电脑端文件读取缓存；mode 0 为 PIXEL，mode 2 为 DIGITAL，并不是原版 PixelBar 的静默模式。尚未找到并验证适用于这台设备的无提示帧更新指令。禁止把未经验证的其他型号指令标记为已支持。

原生文字 E8 是下一步可验证的替代路径，但与自由画布不同，有固定排版和长度限制，不能等价替代自定义图形/进度条。是否更新时无提示仍须实际观察设备。
