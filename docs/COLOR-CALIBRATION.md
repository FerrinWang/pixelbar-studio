# 设备预览与照片外观校准

在“设备与灯光”页面查看当前画布，以及机身灯带的颜色/效果示意。修改设备控件只更新预览草稿，点击“应用设备设置”才向设备发送原始RGB。六种灯效的动画是网页示意，不是固件精确时序或灯带位置复现。

展开“照片颜色校准（仅预览）”：

1. 手动应用一个已知RGB，拍照时记录实际RGB、对象（屏幕/机身）、亮度和灯效。不要把未应用草稿当成设备值。
2. 填入设备RGB，选择照片，点击均匀发光区域取周围5×5像素平均颜色。也可手动填写观测颜色。
3. 保存样本。相同对象/输入RGB的新样本替换旧值；屏幕和机身独立。
4. 预览用照片观测值估计外观，发送RGB保持原值。可停用、删除样本、清空或导入/导出JSON。

建议先拍红、绿、蓝、白、灰，再补黄、青、品红及用户认为偏差严重的颜色：`#FF0000`、`#00FF00`、`#0000FF`、`#FFFFFF`、`#808080`、`#FFFF00`、`#00FFFF`、`#FF00FF`。固定机位、曝光和白平衡，环境光一致，避免过曝和反光。屏幕选较大亮区，机身建议纯色且亮度100%。不要由开发者自动切换硬件测试颜色。

## 能力和限制

- 校准只作用于设备页预览，不改主编辑器RGB、场景、后台上传或设备设置。
- 以线性RGB空间中的观测残差进行距离加权插值；已采样颜色返回对应观测颜色，未采样颜色是近似。没有样本或停用时使用原RGB。
- 照片sRGB的 ΔE76 用于描述输入/观测差异，不是经色度计测得的设备色差。照片曝光、相机处理、屏幕显示器等都会改变结果，不承诺物理精确校色。
- 机身样本不是每个亮度和动画相位的独立测量；非纯色效果由固件生成配色，不能将禁用的RGB控件视为当前硬件配色。
- 当前配置仅存在浏览器 `localStorage` 的 `pixelbar-appearance-calibration-v1`，不会自动在别的浏览器/机器同步；导出文件用来备份。
- 照片最多20MB，读取后最长边缩到1600像素，在浏览器中取色；不上传网络、不写入场景、不持久保存照片。刷新页面会清除照片草稿。
- 校准JSON最多64KB、100样本；只保留 `version`、`enabled`、样本的 `target/input/observed`。不导出照片、路径或认证信息。
